Motorola Sales Dashboard | Power BI

Project Overview

This project presents an interactive Motorola Sales Dashboard built using Microsoft Power BI. It helps analyze sales performance, transactions, customer ratings, mobile models, and payment methods.

Tools Used

- Microsoft Power BI
- Data Visualization
- Data Analysis

Dashboard Features

- Key Performance Indicators (KPIs): Transactions, average value, total quantity, and total sales.
- City-wise Sales: Map visualization to explore sales across cities.
- Sales by Mobile Model: Compare sales across different mobile models.
- Payment Method Analysis: Understand transactions by payment method.
- Quantity by Day: Analyze daily quantity trends.
- Customer Ratings: Explore customer rating patterns.
- Monthly Filter: Select months to explore the dashboard data.

Project Objective

- Analyze sales performance using interactive visuals.
- Compare mobile model sales and payment methods.
- Explore city-wise sales distribution.
- Understand sales and quantity trends.

Project File

"Project Interactive Dashboard.pbix"

Key Learnings

- Building interactive Power BI dashboards.
- Using KPI cards, maps, charts, and slicers.
- Presenting sales data through visualizations.
